# GeoQR V0.2 Build

## Locked sequence

1. Architecture
2. Repository
3. Web MVP
4. Backend
5. Android MVP
6. Encryption
7. Location analytics
8. Production hardening

## Current milestone

**Web MVP + backend contract foundation.**

### Implemented

- Responsive GeoQR creator interface.
- Content type selection for URL, Google Form, PDF, image, video, Word and Excel destinations.
- Browser generation-location permission flow.
- Compact `GQR://v1/<id>/<token>` payload format.
- Client-side QR rendering.
- Local prototype record in browser storage.
- Downloadable QR PNG.
- Backend responsibility boundary.
- Initial OpenAPI contract.

### Not yet production-ready

- Dynamic server-side QR resolution.
- Authentication.
- Persistent database.
- File upload/storage.
- Scanner event ingestion.
- Production E2EE.
- Scanner location analytics.
- Android production client.

These are deliberately deferred rather than simulated in the frontend.
